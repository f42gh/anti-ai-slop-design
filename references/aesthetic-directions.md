# Aesthetic directions and composition

Use this reference to derive a direction from the subject. The vocabulary below is a set of reasoning tools, not a menu of presets.

## Start with cultural and material evidence

Identify:

- the concrete subject and category;
- who is deciding, reading, buying, or operating;
- the screen's single primary job;
- the physical, geographic, cultural, or institutional use scene;
- recognizable materials, instruments, artifacts, marks, language, and production processes;
- the content and assets that are true today;
- constraints fixed by the project and existing implementation.

Avoid cultural shorthand based only on stereotype. When a place, community, tradition, or historical style is central, verify the relevant symbols and usage before borrowing them.

## Choose expressive axes

Place the interface deliberately on each useful axis:

- quiet ↔ theatrical;
- sparse ↔ dense;
- static ↔ kinetic;
- symmetric ↔ directional;
- editorial ↔ operational;
- smooth ↔ tactile;
- archival ↔ immediate;
- institutional ↔ personal;
- diagrammatic ↔ photographic;
- restrained ↔ ornamental.

Do not maximize every axis. A strong direction normally has one dominant tension and disciplined support.

## Branch before selecting

For substantial public or branded work, create three compact candidates that differ in:

- primary visual carrier;
- first-viewport silhouette;
- typography treatment within the allowed font system;
- color deployment and material logic;
- navigation posture;
- section rhythm;
- motion signature.

Reject any candidate that is merely a color swap, could advertise an unrelated product after changing the copy, or violates the project contract.

Describe the selected direction as:

```text
Thesis: one sentence
Type roles: display / body / utility or data
Palette roles: canvas / text / rule / action / state
Layout: macrostructure and reading route
Carrier: real subject, artifact, product state, media, or diagram
Signature: one memorable, justified move
Motion: one primary idea and zero to two support layers
Suppressed defaults: three tempting clichés rejected for this brief
```

## Direction vocabulary

Combine only cues supported by the brief:

- **Editorial / essay:** reading measure, headline rhythm, footnotes, captions, deliberate media cadence.
- **Archive / collection:** index, taxonomy, specimen detail, provenance, stable navigation, quiet comparison.
- **Field guide / manual:** labels, diagrams, observations, coordinates, durable hierarchy, practical annotation.
- **Instrument / control surface:** direct manipulation, precise state, compact density, measured feedback, restrained color.
- **Workshop / craft:** process evidence, material texture, tool marks, scale, sequence, human imperfection used carefully.
- **Public institution:** clarity, civic confidence, multilingual resilience, records, schedules, accessibility as visual structure.
- **Performance / cultural event:** authored sequence, pace, poster logic, strong cropping, time and venue truth.
- **Commerce / object study:** product silhouette, material and scale, option clarity, price and availability, trustworthy detail.
- **Data / research:** comparison, annotation, uncertainty, units, source, freshness, drill-down, disciplined encoding.

These are not themes. For example, “archive” does not automatically mean beige paper, serif type, or faux stamps; derive the actual carrier from the collection.

## Choose the macrostructure

- **Task workspace:** stable navigation, utility layer, primary canvas, contextual secondary region.
- **Data overview:** summary, comparison controls, prioritized data regions, drill-down.
- **Editorial:** reading column, index or metadata rail, deliberate media cadence.
- **Product detail:** inspectable subject, essential facts, configuration, trust details, clear action.
- **Campaign / launch:** immediate subject signal, concise offer, controlled evidence progression.
- **Branded front door:** unmistakable identity, direct entry, authentic output or interaction proof.
- **Reference corpus:** compact wayfinding, search or index, stable measure, continuation.
- **Form flow:** progress context, focused step, inline validation, recovery, completion.

Use the simplest structure that expresses the real relationships. Do not put an operational screen inside a marketing shell or a reading surface inside a dashboard shell.

## Compose the first viewport

1. Make the name, subject, category, artifact, offer, or primary task recognizable immediately.
2. Treat the entry as a thesis, not a generic headline with two buttons.
3. Include one dominant subject, artifact, action, or compositional event.
4. Integrate navigation into the silhouette instead of reflexively using floating pill chrome.
5. Budget header, title, copy, action, proof, media, and the next-region cue together.
6. Test long real copy at short desktop and narrow mobile heights.
7. Recompose priority and crop on mobile; do not scale the desktop composition uniformly.

## Choreograph the page

Map each major region:

```text
job | layout family | type role | evidence or media | density | transition
```

Rewrite adjacent regions that repeat the same alignment, card grid, split, density, or surface treatment without purpose. Establish one display apex. Give the back half its own progression rather than appending a default features/testimonials/CTA chain.

Use proximity before containers. Separate page gutter, section gap, surface inset, internal stack gap, and peer gap as distinct roles. Use visible borders, radius, shadow, blur, texture, transparency, sticky positioning, and scroll snapping only when they improve grouping, hierarchy, orientation, comparison, or sequencing.

## Choose a truthful carrier

Prefer, in order:

1. supplied authentic assets;
2. real screenshots, recordings, data, objects, or code output;
3. appropriate sourced or generated media;
4. a custom code-native diagram or illustration of the real mechanism;
5. an honest, intentionally composed placeholder.

People, places, food, property, travel, and physical craft usually need authentic photography or illustration. Software should show a meaningful real state. Abstract systems should visualize flow, transformation, or output rather than add unrelated atmosphere.
